# Adaptive-Hoeffding-Tree-algorithms-for-real-time-low-resource-cardiac-arrhythmia-detection.
This project evaluates the time-space complexity and performance of four adaptive learning algorithms based on Hoeffding Trees for real-time cardiac arrhythmia detection. It aims to bridge the gap between complex AI models and the need for zero-latency Early Warning Systems in ICUs, ensuring efficient, resource-optimized monitoring.


🔬 Project Brief
This repository provides a rigorous analytical framework for real-time arrhythmia detection. It explores how Adaptive Hoeffding Tree variants can be optimized for Intensive Care Units (ICUs) to balance high predictive accuracy with the extreme computational constraints of edge medical devices.

🚀 Core Research Objectives
Real-Time Processing: Enabling zero-latency anomaly detection in streaming ECG data.

Complexity Analysis: Evaluating the trade-off between time-space complexity and diagnostic performance.

ICU Integration: Establishing a blueprint for upgrading legacy monitoring systems into AI-driven Early Warning Systems (EWS).

📊 Performance Metrics
The models were evaluated based on:

Detection Latency: Time taken from data ingestion to alarm trigger.

Memory Footprint: RAM utilization during stream processing.

Predictive Accuracy: F1-Score and AUC in non-stationary data environments.

💡 Why this matters?
In critical care, milliseconds save lives. This research demonstrates that advanced adaptive algorithms can function efficiently on edge devices, moving us closer to truly proactive, personalized healthcare monitoring.
